# BotForTwitch

Twitch-бот для стримов [MrIceRam](https://twitch.tv/MrIceRam) по [DDNet](https://ddnet.org) и Dota 2.
Бот раз в минуту смотрит категорию стрима и включает только то, что подходит игре:

| Категория | Что работает |
|---|---|
| DDNet | чат Twitch в игре, реклама стрима, `!invite`, реверс управления за баллы |
| Dota 2 | сообщения зрителей в общий чат игры и нажатие способностей за баллы. В DDNet бот ничего не отправляет |
| оффлайн или другая игра | только команды, которым игра не нужна: `!points`, `!map`, `!roll` |

Название категории бот пишет в консоль при каждой смене.

## Команды

| Команда | Что делает |
|---|---|
| `!invite <ник>` | Инвайтит игрока в команду в DDNet (только на стримах по DDNet) |
| `!points <ник>` | Очки игрока с ddnet.org |
| `!map [ник]` | На какой карте и сервере сейчас игрок (без ника — `IceRam`) |
| `!roll` | Случайное число от 0 до 100 |

А ещё бот:
- на стримах по DDNet пересылает все сообщения из чата в консоль DDNet и каждые 5 минут пишет рекламу стрима в чат DDNet;
- отвечает на некоторые фразы (список в `src/commands/answer.js`).

## Что нужно

- Windows
- [Node.js](https://nodejs.org) 18+
- [Python](https://www.python.org) 3
- Клиент DDNet

## Установка

```bash
npm install
pip install -r requirements.txt or py -m pip install -r requirements.txt
```

Файл `.env` заполняется сам. Запустите:

```bash
npm run setup
```

Откроется браузер ([twitchtokengenerator.com](https://twitchtokengenerator.com)) — войдите аккаунтом канала
и нажмите «Authorize». Бот сам запишет в `.env` `TWITCHUSER`, `OAUTH`, `CLIEN` и `REFRESH`.
Если `.env` нет, то же самое произойдёт при `npm start`.
При каждом запуске бот сам обновляет `OAUTH`.

> [!WARNING]
> Не выкладывайте `.env` — в нём доступ к каналу. Он уже в `.gitignore`.
> TWITCHUSER	Ник канала (логин, например MrIceRam)
> OAUTH	Токен доступа (access token)
> CLIEN	ID клиента (client id)
> REFRESH	Токен обновления (refresh token)

В консоли DDNet (F1) один раз выполните и перезапустите клиент:

```
cl_input_fifo ddnet_client
```

## Запуск

Запустите DDNet, зайдите на сервер, затем:

```bash
npm start
```

## Награды за баллы канала

Все награды настраиваются в `REWARDS` в начале `src/index.js`.

### «Реверс» (DDNet)

На 30 секунд меняются местами `A`↔`D`, `W`↔`S` и кнопки мыши.

- Награда узнаётся по id. Свой id бот пишет в консоль при погашении награды.
- Остановить досрочно: `"unblock": "True"` в `config/blocking.json` (потом верните `"False"`).
- Если в игре не работает — запустите бота от имени администратора.

### Награды для Dota 2

Создайте на Twitch две награды ровно с такими названиями и включите в обеих «Требовать ввод текста»:

| Название награды | Что пишет зритель | Что происходит |
|---|---|---|
| `Сообщение в чат Доты` | текст сообщения | Shift+Enter, текст, Enter — сообщение в общий чат игры (до 120 символов, одной строкой) |
| `Способность в Доте` | одна буква: `q` `w` `e` `r` `d` `f` (или `й` `ц` `у` `к` `в` `а`) | нажимается эта способность |

- Бот нажимает клавиши, только если на экране сейчас Дота. Иначе он пишет зрителю в чат, что не получилось, и ничего не печатает в другие окна.
- Баллы Twitch за неудачную попытку сам не возвращает, их можно вернуть вручную в очереди наград.
- Сообщения зрителей уходят в общий чат от вашего аккаунта. За оскорбления в чате Valve может наказать именно вас, поэтому следите за текстом или поставьте на награду проверку модератором.

## Проверка без стрима

Добавьте в `.env` строку, и бот будет считать, что стрим идёт в этой категории:

```
FORCE_GAME=Dota 2
```

или `FORCE_GAME=DDNet`. Не забудьте убрать её перед настоящим стримом.
